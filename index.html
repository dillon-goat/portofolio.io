Tugas AkhirCapstone Project

Capstone · Computer Vision · Raspberry Pi · API RP 19C

Rancang Bangun Sistem Pengolahan Citra untuk Pengukuran Sphericity Pasir Proppant Design and Development of an Image-Processing System for Proppant Sand Sphericity Measurement

Sistem pengukuran tingkat kebulatan (sphericity) butiran pasir proppant secara otomatis menggunakan pengolahan citra digital. Proppant adalah material granular kritis dalam proses hydraulic fracturing (fracking) sumur migas — kualitasnya sangat mempengaruhi permeabilitas retakan dan produktivitas sumur. Sistem ini mengikuti standar API RP 19C dengan formula sphericity = (Dmin/Dmax) × 100% dan mengklasifikasikan butiran ke dalam 4 kategori kualitas. Dibangun modular dengan Python & OpenCV pada Raspberry Pi 5 dengan antarmuka layar sentuh DSI. An automated system for measuring the sphericity of proppant sand grains using digital image processing. Proppant is a critical granular material in hydraulic fracturing (fracking) of oil & gas wells — its quality strongly affects fracture permeability and well productivity. The system follows the API RP 19C standard using the formula sphericity = (Dmin/Dmax) × 100% and classifies grains into 4 quality categories. Built modularly with Python & OpenCV on a Raspberry Pi 5 with a DSI touchscreen interface.
